  le code Matomo standard ne compterait que la première page.
- Le `trackPageView` d'origine est supprimé ; un écouteur `turbo:load` envoie une page vue à chaque
  navigation (chargement initial compris) avec `setCustomUrl`, `setDocumentTitle` et `setReferrerUrl`.
